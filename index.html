Try LinkLens on your computer

Localhost refers to your own computer. Start the server there before opening the app; this portfolio cannot start it for you.

  1. Download or clone the project from GitHub ↗, then open a terminal in the downloaded project folder. Use the version that includes LinkLens.
  2. Make sure Ruby is installed. If WEBrick is missing, run gem install webrick.
  3. Start the server and keep the terminal open: 
    ruby link-checker/server.rb
  4. Open the app using the button below. To stop the server later, press Ctrl + C in the terminal.
Open LinkLens on localhost ↗

If the page cannot be reached, check that the server is running on port 8081 on this computer.
